CORE DIGITAL LOGIC

Finite State Machine (FSM) and Algorithmic State Machine (ASM)

1. Sequential Logic

A sequential circuit is a digital circuit whose output depends on the present input and the previous state of the circuit.

Present State + Input → Next State

Important Elements

  • Input
  • Output
  • State
  • Flip-Flops / Memory Elements
  • Clock

2. Finite State Machine (FSM)

A Finite State Machine is a mathematical model used to represent the behavior of a sequential digital system using a finite number of states and transitions.

Main Components

  • State: Represents the current condition of the system.
  • Input: Signal that affects the transition.
  • Output: Result produced by the system.
  • Transition: Movement from one state to another.
  • Clock: Controls state changes in synchronous systems.

5. Moore Machine

In a Moore machine, the output depends only on the present state.

Present State → Output

6. Mealy Machine

In a Mealy machine, the output depends on both the present state and the input.

Present State + Input → Output

7. Moore vs Mealy

Feature Moore Mealy
Output depends on Present State Present State + Input
Output associated with State Transition
Response State dependent Input and state dependent

8. Algorithmic State Machine (ASM)

An Algorithmic State Machine is a graphical representation used to describe the sequence of operations and decisions in a synchronous digital system.

Basic ASM Elements

  • State Box: Represents operations performed during a particular state.
  • Decision Box: Represents a condition used to determine the next path.
  • Conditional Output Box: Represents an output generated when a specific condition is true.
  • Flow Lines: Show the sequence between states and decisions.

10. Synchronous FSM

In a synchronous FSM, state transitions take place according to a clock signal.

The state register stores the present state. At the active clock edge, the next state is loaded into the state register.

12. FSM and ASM Relationship

FSM and ASM are two ways of representing sequential digital systems.

FSM ASM
Represents states and transitions Represents states, decisions and operations
Usually represented using a state diagram Usually represented using an ASM chart
Focuses on state behavior Focuses on sequential algorithmic behavior
Key idea: FSM describes what state the system is in and how it changes, while ASM describes the sequence of operations and decisions associated with those states.

13. Key Points

  • Sequential circuits have memory.
  • FSM represents a system using a finite number of states.
  • State diagrams show transitions between states.
  • State tables describe present state, input and next state.
  • Moore output depends on the present state.
  • Mealy output depends on present state and input.
  • ASM represents states, operations and decisions.
  • Synchronous FSMs use a clock for state transitions.
  • FSM and ASM are useful methods for designing sequential digital systems.
