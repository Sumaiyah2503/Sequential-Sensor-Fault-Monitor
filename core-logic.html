ASM State Flow

NORMAL → WARNING → FAULT → RECOVERY → NORMAL
ASM represents the sequential decision-making flow of the system.

Core Digital Logic

  • Sensor values are compared with predefined threshold values.
  • The sensor condition is classified as NORMAL or ABNORMAL.
  • FSM determines the current state and next-state transition.
  • ASM represents the sequential decision-making process.
  • State changes occur only when a clock pulse is applied.
