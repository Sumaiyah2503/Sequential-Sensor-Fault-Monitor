Synchronous Sequential Circuit

A synchronous sequential circuit is a digital circuit whose state changes occur in synchronization with a clock signal.

The next state depends on the present state and the input conditions.

Sequential Sensor Fault Monitor

This project applies synchronous sequential circuit concepts to monitor temperature, pressure and vibration sensor inputs.

The system updates its state only when a clock pulse is applied.

Basic Operation

Sensor Inputs → Threshold Checking
Threshold Result → Sensor Condition
Present State + Sensor Condition → Next State
CLOCK PULSE → State Update

Sensor Inputs

Sensor Normal Condition Abnormal Condition
Temperature ≤ 50 °C > 50 °C
Pressure 90 – 110 kPa Outside range
Vibration ≤ 5 mm/s > 5 mm/s

System States

State Meaning
NORMAL No abnormal sensor condition
WARNING Abnormal condition detected once
FAULT Abnormal condition continues
RECOVERY Normal condition detected after fault

FINITE STATE MACHINE (FSM)

What is FSM?

A Finite State Machine is a sequential model consisting of a finite number of states and transitions between those states.

FSM in This Project

The sensor fault monitor uses four states: NORMAL, WARNING, FAULT and RECOVERY.

State Transition Logic

Present State Sensor Condition Next State
NORMAL NORMAL NORMAL
NORMAL ABNORMAL WARNING
WARNING NORMAL NORMAL
WARNING ABNORMAL FAULT
FAULT NORMAL RECOVERY
FAULT ABNORMAL FAULT
RECOVERY NORMAL NORMAL
RECOVERY ABNORMAL FAULT

Synchronous FSM

In this project, the state transition occurs only when the CLOCK PULSE is applied. Therefore, the FSM operates synchronously.

ALGORITHMIC STATE MACHINE (ASM)

What is ASM?

An Algorithmic State Machine is a graphical method used to represent the sequential operation of a digital system.

ASM Elements

State Box

Represents a state or operation performed by the sequential circuit.

Decision Box

Represents a condition that determines the next operation.

Conditional Output

Represents an output produced when a particular condition is satisfied.

Transition

Shows movement from one state to another based on the decision condition.

ASM in This Project

The ASM representation describes the sequential sensor monitoring process using states and decision conditions.

START / RESET
↓
NORMAL
↓ Sensor condition check
ABNORMAL? → YES → WARNING

ASM and Clock

The state transition occurs synchronously with the clock pulse. This connects the ASM representation with the synchronous sequential circuit design used in this project.
