FSM and ASM

FSM:

A Finite State Machine represents the states of a sequential system and the transitions between those states.

ASM:

An Algorithmic State Machine represents the algorithmic operation of a synchronous sequential system using states, decisions and conditional operations.

FSM vs ASM

FSM ASM
Represents states and transitions Represents algorithmic operation
State diagram is commonly used ASM chart is commonly used
Focuses on state behaviour Shows states, decisions and operations
Shows how the system moves between states Shows how the system performs operations step by step

Finite State Machine (FSM)

Definition

A Finite State Machine is a model of a sequential system that uses a finite number of states. The next state is determined by the present state and input.

Moore and Mealy Machines

Moore Machine

The output depends only on the present state.

Mealy Machine

The output depends on the present state and input.

Synchronous FSM

In a synchronous FSM, state transitions occur according to the clock signal. The state register changes only at the required clock event.

Algorithmic State Machine (ASM)

Definition

An Algorithmic State Machine (ASM) is a method used to represent the operation of a synchronous sequential circuit using states, decision conditions and conditional operations.

ASM Elements

  • State Box: Represents the operation performed in a state.
  • Decision Box: Represents a condition or decision.
  • Conditional Output: Represents an operation performed when a particular condition is satisfied.
  • Clock: Controls the timing of state changes.

FSM and ASM Difference

FSM ASM
