FSM and ASM

FSM: Represents states and transitions of a sequential system.

ASM: Represents the algorithmic operation of a sequential system using states, decisions and conditional operations.

Finite State Machine (FSM)

What is FSM?

A Finite State Machine is a model of a sequential system that uses a finite number of states and transitions between states. The transition depends on the input and the present state.

Moore vs Mealy

Moore Machine

Output depends only on the present state.

Mealy Machine

Output depends on the present state and input.

Synchronous FSM

In a synchronous FSM, state transitions are controlled by a clock signal.

Algorithmic State Machine (ASM)

What is ASM?

An Algorithmic State Machine is a flowchart-like representation used to describe the operation of a synchronous sequential digital system.

ASM Elements

State Box

Represents the operations performed in a state.

Decision Box

Represents a condition that determines the next path.

Conditional Output

Represents an operation performed only when a condition is true.

Transition

Shows movement from one state to another.
