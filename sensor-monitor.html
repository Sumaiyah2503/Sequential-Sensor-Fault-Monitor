SYNCHRONOUS SEQUENTIAL CIRCUIT

Sequential Sensor Fault Monitor

Problem Statement

Sensor readings such as temperature, pressure and vibration may become abnormal during system operation. The system must detect abnormal sensor conditions and monitor them sequentially using synchronous sequential logic.

Software Solution

This software simulates a synchronous sequential sensor fault monitor. Sensor inputs are checked against threshold values. The FSM and ASM based sequential logic updates the state only when a CLOCK PULSE is applied.
